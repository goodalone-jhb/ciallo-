使用EIDE开发，PCB上仅有一个红灯为充电指示灯，充电无视开关状态，直接使用C口线充电即可，我打了5.1kΩ电容。

补丁：需要将R5更换为62KΩ（圆桌上的白色塑料料带中的电阻）（注意R5位置）

测试流程：除舵机、开关外完全焊接，测试充电，期望指示灯亮起——焊接开关并打开，测电池电压，期望电池已被充电激活（如未激活就再充一会），测3V3和5V轨电压，期待3V3和3.8(电压大概率会稍微低一点)——使用daplink按压烧录，完成后焊接一路舵机，舵机顺序为从陀螺仪测开始3个为一组按照GND-VCC-SIG的顺序，焊接后上电舵机完成扫动自检后，左右转动PCB，舵机抖动（异常情况：舵机抖动不随PCB且每隔几秒抖动3/4次——陀螺仪I2C通信失败）
